# Sound assets

Drop your own audio files here and they'll be picked up automatically —
no code changes needed. Supported formats: `.mp3`, `.wav`, `.ogg` (tried
in that order for each name).

| Filename (any supported extension) | Used for |
|---|---|
| `se_game_answer` | Critical Perfect and Perfect judgement (shared sound) |
| `se_game_great`  | Great judgement |
| `se_game_good`   | Good judgement |
| `se_game_click`  | Count-in / lead-in beats |

Until a file is present, that sound falls back to a synthesized
placeholder tone, so the app works either way.
